# RoadHunter

A small browser hunting game made for friends and family, set on the real terrain near Salmon, Idaho.
Play it at the GitHub Pages link for this repo. Works on phones (turn sideways) and desktop.

- Roads, rivers and buildings: © OpenStreetMap contributors, ODbL (https://www.openstreetmap.org/copyright).
- Characters and animations: Quaternius "Universal Base Characters" and "Universal Animation Library" (CC0).

All dialogue is made-up parody among friends. Game hunting mechanics are not real hunting advice.
